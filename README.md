# Site Web Charpentier 🪵

Site web professionnel pour entreprise de charpente et construction bois.

## Fonctionnalités

- ✅ Design responsive (mobile & desktop)
- ✅ Section héro avec call-to-action
- ✅ Page portfolio pour charpente traditionnelle
- ✅ Section éducative sur les avantages du bois
- ✅ Poutre animée interactive avec formulaire de contact
- ✅ Animations de feux d'artifice

## Structure du Projet

```
CHARPENTES/
├── index.html                          # Page d'accueil
├── charpente-traditionnelle.html       # Portfolio
├── styles.css                          # Styles
├── script.js                           # JavaScript
├── assets/                             # Images
├── .gitignore                          # Configuration Git
└── README.md                           # Ce fichier
```

## Démarrage Rapide

1. Ouvrez `index.html` dans votre navigateur
2. Ajoutez vos propres photos dans `assets/`
3. Personnalisez les textes selon vos besoins

## Déploiement

Consultez le fichier **`deployment_guide.md`** (dans les artifacts) pour les instructions détaillées de déploiement vers GitHub et Netlify.

### Prérequis

- [Git](https://git-scm.com/downloads) installé sur votre machine
- Compte [GitHub](https://github.com)
- Compte [Netlify](https://netlify.com)

## Technologies

- HTML5
- CSS3 (animations, gradients, flexbox, grid)
- JavaScript (vanilla)
- Font Awesome (icônes)
- Google Fonts (Outfit, Playfair Display)
